# APUE Study

A personal study repository for *Advanced Programming in the UNIX Environment* by W. Richard Stevens and Stephen A. Rago.

## Objectives

- Understand Unix and POSIX system programming.
- Explore file I/O, processes, signals, threads, and interprocess communication.
- Implement practical examples of Unix system calls and library functions.
- Solve textbook exercises and document concepts, experiments, and observations.
- Build a strong foundation in Linux and systems programming.

## Directory Overview

- `docs/` — References and build documentation.
- `examples/` — Standalone C programs.
- `exercises/` — Textbook exercises and solutions.
- `include/` — Shared headers and declarations.
- `logs/` — Learning progress and experiment logs.
- `notes/` — Chapter-wise notes and explanations.
- `scripts/` — Build and maintenance scripts.
- `tests/` — Tests for selected programs.
- `Makefile` — Build automation.

## Environment

- **Operating system:** Ubuntu 22.04 LTS (Jammy Jellyfish)
- **Language:** C
- **Compiler:** GCC
- **Build system:** GNU Make
