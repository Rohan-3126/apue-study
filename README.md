# APUE Study

A personal study repository for *Advanced Programming in the UNIX Environment*
by W. Richard Stevens and Stephen A. Rago.

## Objectives

- Understand Unix and POSIX system programming.
- Explore file I/O, processes, signals, and interprocess communication.
- Implement practical examples of Unix system calls.
- Document concepts, experiments, and observations.

## Repository Structure

- `notes/` — Personal notes and concept summaries.
- `exercises/` — Chapter-wise exercise solutions.
- `examples/` — Focused demonstrations of system interfaces.
- `include/` — Shared header files.

## Environment

- Operating system: Linux
- Language: C
- Build system: GNU Make
